# Chapter 1 - Introduction to Linux

## What is Linux?

Linux is a free and open-source operating system based on Unix. It acts as an interface between the user and the computer hardware by managing system resources such as CPU, memory, storage, and devices.

Linux is widely used in Cloud Computing, DevOps, Web Servers, Containers, and Enterprise environments because of its stability, security, flexibility, and performance.

---

# What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and software resources. It acts as a bridge between the user and the hardware.

### Responsibilities of an Operating System

- Process Management
- Memory Management
- File Management
- Device Management
- Security
- User Management
- Networking

# Types of Operating Systems

## 1. Batch Operating System

Executes a batch of jobs without user interaction.

Example:
- Payroll Processing

---

## 2. Time Sharing Operating System

Allows multiple users to use the system simultaneously.

Examples:
- Linux
- UNIX

---

## 3. Distributed Operating System

Multiple computers work together as one system.

Example:
- Cluster Computing

---

## 4. Network Operating System

Allows communication and resource sharing over a network.

Examples:
- Windows Server
- Ubuntu Server

---

## 5. Real-Time Operating System (RTOS)

Provides immediate response for time-critical applications.

Examples:
- Air Traffic Control
- Medical Equipment

---

## 6. Embedded Operating System

Designed for embedded devices.

Examples:
- Smart TVs
- Routers
- ATM Machines

---

# What is a Server?

A server is a computer or software application that provides services, resources, or data to other computers (clients) over a network.

### Examples

- Web Server
- Database Server
- File Server
- Mail Server
- DNS Server

# Linux Architecture

Linux architecture consists of four major layers.

```text
+------------------------------+
|      User Applications       |
+------------------------------+
|            Shell             |
+------------------------------+
|           Kernel             |
+------------------------------+
|          Hardware            |
+------------------------------+
```

## Hardware

Physical components of a computer.

Examples:

- CPU
- RAM
- Hard Disk
- Motherboard
- Network Card

---

## Kernel

The Kernel is the core of the Linux operating system.

### Responsibilities of Kernel

- Memory Management
- Process Management
- Device Management
- File System Management
- Security
- Scheduling

---

## Shell

The Shell is the command interpreter that allows users to communicate with the Kernel.

Popular Linux Shells:

- Bash
- Zsh
- Ksh
- Fish

---

## User Space

Users interact with Linux through applications and commands.

Examples:

- Firefox
- VS Code
- Docker
- Git
- Kubernetes CLI
